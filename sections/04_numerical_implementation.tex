\section{Numerical Implementation}

This section describes the discrete fields, the transport--chemistry coupling,
and the per-timestep algorithm used in the reported simulations. The
implementation couples conservative Darcy-Brinkman-Stokes (DBS) transport
\citep{soulaine2016micro} with cell-centred PHREEQC chemistry
\citep{parkhurst2013phreeqc} and cell-based surface complexation in a single
operator-split formulation.

\subsection{Field Locations And Discretization}

The baseline discretization keeps all chemistry-bearing state cell-centered.
This avoids introducing an extra face reconstruction for the unresolved
surface-reaction source. The solution species, $\theta$,
$\epsilon_{\mathrm{num}}$, $a_{\mathrm{surf}}$, and the surface fields are
therefore stored at cell centres, whereas only the volumetric flux $\phi$
remains face-centred. Transport uses face interpolation only within the
conservative flux assembly, while the surface chemistry remains strictly
cell-local.

For microporous image cases, the current implementation treats the cell-centered
surface-area field as an additive quantity:
\[
    a_{\mathrm{surf}} =
    a_{\mathrm{surf}}^{\mathrm{interface}} +
    a_{\mathrm{surf}}^{\mathrm{intrinsic}}.
\]
The first term is the coarse-grained phase-boundary contribution. The second is
an intrinsic volumetric surface density assigned to selected image phases
(for example the micropore phase) and scaled by the corresponding local phase
fraction inside each coarse cell \citep{menke2021upscaling}.

\subsection{PHREEQC Coupling}

The PHREEQC coupling is performed through \texttt{phreeqcDBSMixture}, which
wraps the PhreeqcRM interface \citep{parkhurst2015phreeqcrm}. For each cell,
the coupling uses the current aqueous state, the physical mobile-water fraction
$\theta$, the current cell surface area $a_{\mathrm{surf}}$ including any
intrinsic micropore contribution, and the current cell surface state. The
surface mode is optional and reduces exactly to aqueous-only mode when
$a_{\mathrm{surf}} = 0$.

Cells with negligible mobile-water fraction remain chemically inactive in the
finite-volume state. This is enforced at the field level; the PHREEQC backend
retains an internal dummy water volume only to maintain numerical
well-posedness of the chemistry module.

\subsection{Per-Timestep Algorithm}

The production timestep uses a first-order Lie splitting
\citep{steefel1994coupled}. At each step, the solver reads or updates the face
flux $\phi$, advances each aqueous transport equation in conservative DBS form,
pushes the updated cell state into PHREEQC, executes the local chemistry
update, and pulls the updated aqueous and surface states back into the
finite-volume fields. Integrated inventory diagnostics are written at each
step. The operator-split structure keeps transport and chemistry individually
testable and ensures that the conservative structure of the aqueous transport
step is not hidden inside a composite implicit source term.

Figure~\ref{fig:dbsWorkflow} illustrates the implemented algorithm. The
chemistry state remains cell-centred throughout the loop. The solver does not
reconstruct a face-based reaction source for the unresolved surface term.
Instead, the transport operator acts on cell inventories through the face
fluxes, while the reaction operator acts locally on the updated cell state
through PHREEQC \citep{parkhurst2013phreeqc}.
