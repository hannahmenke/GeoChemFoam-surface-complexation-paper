\subsection{Simple 2D Image-Based Case}

The 2D demonstration reuses the segmented image
\texttt{4StraightFractures.raw.tar.gz} (stored under
\texttt{images/raw/}) with metadata in \texttt{4StraightFractures.txt}. The
source image has dimensions
$500 \times 500 \times 1$ and contains two labels, corresponding to matrix
($1$) and pore ($2$). The associated runtime case is the tracked
\texttt{4StraightFracturesSurfaceComplexation} case, which is solved on a
$250 \times 250 \times 1$ computational grid. This case serves the same role
as the simple 2D example in the reference paper: it provides a geometrically
transparent setting in which the coupling between transport, unresolved
surface interaction, and retardation remains easy to interpret.

In this image, the source metadata reserves label \mbox{$0 = \mathrm{solid}$},
but the actual raw data contain only matrix and pore labels. For the unresolved
DBS surface term, the present implementation therefore treats the matrix phase
(\mbox{$1$}) as the reactive solid-like phase when constructing
\mbox{$a_{\mathrm{surf}}$}. This is the correct interpretation for this
fracture-network example because the reactive interface is the matrix-pore
contact, not a separate label-\mbox{$0$} solid.

The corresponding figure reports the segmented geometry, the normalized
dissolved calcium field, and the normalized adsorbed-calcium field.

At the reported endpoint ($t = 3000$), obtained on eight MPI ranks, the
case exhibits nonzero $a_{\mathrm{surf}}$ and \texttt{Surf\_aCa+} fields and
produces a reproducible three-panel figure tied directly to the runtime case.
An intrinsic unresolved surface term is included inside the
$\epsilon = 0.4$ matrix phase, so the surface-loading field is no longer
confined to the matrix--pore interface. Accordingly, the 2D case is used to
demonstrate that the method reproduces the expected directional retardation
pattern in a simple geometry, that the surface-loading field tracks both the
fracture walls and the microporous matrix in an interpretable manner, and that
the image-based formulation remains visually and numerically transparent before
the transition to 3D.

\subsection{Simple 3D Image-Based Case}

The simple 3D case reuses the Kelvin image data set distributed with the
repository together with its accompanying metadata file.
The image dimensions are
$200 \times 200 \times 200$, the voxel size is $10~\mu\mathrm{m}$, and the
rendering convention used in the manuscript treats label $1$ as pore and label
$2$ as micropore. This case marks the transition from 2D transport pathways to
a fully 3D unresolved surface network while remaining sufficiently simple to
interpret visually. It is used to illustrate how the 3D topology modifies the
transport path, how the unresolved internal surface distribution reshapes the
uptake pattern, and how the cost of the chemistry step increases relative to
the 2D case.

The 3D chemistry figures reported here are true volume renders generated from
the stitched solver fields. Earlier slice-based views were useful during
internal verification, but they are not used as final manuscript figures.

For the 3D cases considered here, the transported initial condition is
calcium-free (\mbox{$\mathrm{Ca^{2+}} = 0$}, \mbox{$\mathrm{Cl^{-}} = 0$}) and
all visible calcium enters through the inlet boundary. A tiny trace remains
only in the PHREEQC template input so the upgraded backend retains the
calcium component during startup mapping. The reported surface panel is
therefore plotted as incremental loading
(\mbox{$\Delta$\texttt{Surf\_aCa+}}) rather than absolute
\texttt{Surf\_aCa+}, which removes the negligible startup equilibrium floor.

\subsection{Large 3D Porous-Media Case}

The large 3D porous-medium case reuses
\texttt{Est\_3phase500cubed4micron.raw.tar.gz} (under \texttt{images/raw/})
with metadata in \texttt{Est\_3phase500cubed4micron.txt}. The image dimensions are
$500 \times 500 \times 500$, the voxel size is $4~\mu\mathrm{m}$, and the
three phases correspond to pore ($1$), micropore ($2$), and solid ($3$). This
case serves as the application-scale demonstration. By using an
Estaillades-style multi-scale image, the formulation is exercised on a domain
with substantially stronger structural contrast than the controlled 2D and
simple 3D cases. In this setting, the manuscript reports the image and
mesh dimensions, the effective coarse resolution, the visible multi-scale
contrast in the volume rendering, the MPI rank count, a representative runtime,
and one concentration and one surface-loading metric that remain comparable to
the earlier examples.

The corrected Estaillades case is reported here from a clean unrestarted run
to $t = 50$ on eight MPI ranks, using a $50 \times 50 \times 50$ coarse grid
constructed from the full $500^3$ segmented image. For this run, the
domain-mean dissolved Ca$^{2+}$ is $5.37 \times 10^{-10}$, the domain-mean
\texttt{Surf\_aCa+} is $2.12 \times 10^{-15}$, and the mean
$a_{\mathrm{surf}}$ is $7.65 \times 10^{4}\ \mathrm{m^{-1}}$. The PHREEQC
timing summary reports $10$ chemistry calls with a total chemistry time of
approximately $7.29$~s, while the total wall-clock time to the final written
state is approximately $25$~s.

The current large-3D chemistry result is physically consistent with the case
setup: the near-solid cells (\mbox{$\theta \le 10^{-3}$}) are now masked out of
the reactive-surface field, so the reported adsorption is concentrated in the
microporous and macroporous mobile regions rather than the numerically regularized
solid skeleton.
