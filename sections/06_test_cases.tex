\section{Test Cases}

Table~\ref{tab:simParams} lists the full set of simulation parameters for each
test case. All cases use the same dilute calcium surface-complexation system
\citep{pokrovsky2002surface,heberling2011structure}:
$C_{\mathrm{in}}(\mathrm{Ca^{2+}}) = 2\times10^{-9}\ \mathrm{mol\,m^{-3}}$,
$C_{0}(\mathrm{Ca^{2+}}) = 0$, mobile-water threshold
$\theta_{\mathrm{mask}} \le 10^{-3}$, and the PHREEQC surface-complexation
input from the tutorial cases distributed with GeoChemFoam. The 1D case
uses a prescribed uniform inlet velocity $U = 10^{-6}\ \mathrm{m\,s^{-1}}$;
the 2D and 3D image-based cases use a velocity field obtained from a
prior \texttt{simpleDBSFoam} flow calculation with pressure drop
$\Delta P = 5\times10^{-5}\ \mathrm{Pa}$ and kinematic viscosity
$\nu = 10^{-6}\ \mathrm{m^{2}\,s^{-1}}$.

\subsection{Simple 2D Image-Based Case}

The 2D demonstration uses the segmented fracture-network image
\texttt{4StraightFractures} with dimensions
$500 \times 500 \times 1$ and two labels corresponding to matrix ($1$) and
pore ($2$). The computational grid is $250 \times 250 \times 1$.
This case provides a geometrically transparent setting in which the coupling
between transport, unresolved surface interaction, and retardation remains easy
to interpret visually and analytically.

In this image, the reactive interface is the matrix-pore contact. The matrix
phase ($1$) is therefore treated as the reactive solid-like phase when
constructing $a_{\mathrm{surf}}$. An intrinsic unresolved surface term is
included inside the $\epsilon = 0.4$ matrix phase, so the surface-loading field
is no longer confined to the matrix-pore interface but extends across the
microporous matrix.

Figure~\ref{fig:2DFractures} reports the segmented geometry, the normalized
dissolved calcium field, and the normalized adsorbed-calcium field at
$t = 3000$, obtained on eight MPI ranks. The 2D case demonstrates that the
method reproduces the expected directional retardation pattern in a simple
geometry and that the surface-loading field tracks both the fracture walls and
the microporous matrix in an interpretable manner.

\subsection{Simple 3D Image-Based Case}

The simple 3D case uses a Kelvin-cell image dataset with dimensions
$200 \times 200 \times 200$ and voxel size $10~\mu\mathrm{m}$, where
label $1$ denotes pore and label $2$ denotes micropore.
This case marks the transition from 2D transport pathways to a fully
three-dimensional unresolved surface network while remaining sufficiently
simple to interpret visually. The 3D topology produces preferential transport
channels and a structured surface-uptake pattern that can still be read
directly from the volume renders.

The transported initial condition is calcium-free
(\mbox{$\mathrm{Ca^{2+}} = 0$}, \mbox{$\mathrm{Cl^{-}} = 0$}) and all
visible calcium enters through the inlet boundary. The surface panel is
reported as incremental loading
(\mbox{$\Delta$\texttt{Surf\_aCa+}} = \texttt{Surf\_aCa+}$(t)$ $-$
\texttt{Surf\_aCa+}$(0)$) to isolate the transport-driven uptake from the
negligible startup equilibrium floor retained by the PHREEQC template.
Figure~\ref{fig:3DKelvin} shows the geometry, dissolved-calcium, and
incremental surface-loading panels at $t = 4$.
Figure~\ref{fig:KelvinTemporal} shows the evolution of the domain-mean
dissolved and adsorbed calcium over the full simulation to $t = 400$~s.
The domain-mean Ca$^{2+}$ rises monotonically as calcium-bearing fluid
displaces the initial calcium-free condition, while the normalised incremental
surface loading tracks the aqueous saturation with a lag that reflects the
finite surface uptake kinetics resolved by the PHREEQC equilibrium step.

\subsection{Large 3D Porous-Media Case}

The large 3D porous-medium case uses an Estaillades-style three-phase
segmented image \citep{menke2021upscaling} with dimensions
$500 \times 500 \times 500$ and voxel size $4~\mu\mathrm{m}$. The three phases
correspond to pore ($1$), micropore ($2$), and solid ($3$). The simulation is
run on a $50 \times 50 \times 50$ coarse grid on eight MPI ranks. This case
serves as the application-scale demonstration of the method on a domain with
substantially stronger structural contrast than the controlled 2D and simple 3D
cases.

The run proceeds to $t = 50$ from a clean unrestarted start. At this
endpoint, the domain-mean dissolved Ca$^{2+}$ is $5.37 \times 10^{-10}$, the
domain-mean \texttt{Surf\_aCa+} is $2.12 \times 10^{-15}$, and the mean
$a_{\mathrm{surf}}$ is $7.65 \times 10^{4}\ \mathrm{m^{-1}}$. The PHREEQC equilibrium solve accounts for approximately $29\%$ of the
$\approx 25$~s wall-clock time, consistent with the per-cell cost scaling
observed in the 1D sensitivity studies.

Near-solid cells (\mbox{$\theta \le 10^{-3}$}) are masked out of the
reactive-surface field, so the reported adsorption is concentrated in the
microporous and macroporous mobile regions rather than the numerically
regularized solid skeleton. Figure~\ref{fig:3DEstaillades} shows the
geometry and field panels at $t = 50$.
