\subsection{Simple 2D Image-Based Case}

The implemented 2D case reuses the existing segmented image asset:
\begin{itemize}
\item \texttt{images/raw/4StraightFractures.raw.tar.gz}
\item metadata: \texttt{images/raw/4StraightFractures.txt}
\item image size: \mbox{$500 \times 500 \times 1$}
\item raw labels present in the image:
      \mbox{$1 = \mathrm{matrix}$}, \mbox{$2 = \mathrm{pore}$}
\item draft runtime case:
      \texttt{tutorials/reactiveTransport/reactiveScalarTransportDBSFoam/}
      \texttt{4StraightFracturesSurfaceComplexation}
\item draft runtime mesh:
      \mbox{$250 \times 250 \times 1$}
\end{itemize}

This case should play the same role as the simple 2D case in the reference
paper: a geometrically transparent test that makes the coupling between
transport, internal surface interaction, and retardation easy to interpret.

In this image, the source metadata reserves label \mbox{$0 = \mathrm{solid}$},
but the actual raw data contain only matrix and pore labels. For the unresolved
DBS surface term, the current draft therefore treats the matrix phase
(\mbox{$1$}) as the reactive solid-like phase when constructing
\mbox{$a_{\mathrm{surf}}$}. This is the correct interpretation for this
fracture-network example because the reactive interface is the matrix-pore
contact, not a separate label-\mbox{$0$} solid.

Reported figure set:
\begin{itemize}
\item geometry panel,
\item normalized aqueous calcium panel,
\item normalized adsorbed-calcium panel.
\end{itemize}

At the current draft endpoint (\mbox{$t = 2000$}, run on \mbox{$8$} MPI
ranks), the case has a nonzero \mbox{$a_{\mathrm{surf}}$} field, a nonzero
\texttt{Surf\_aCa+} field, and a clean three-panel PNG tied directly to the
runtime case. The 2D case is now written to answer three questions:
\begin{enumerate}
\item does the method recover the expected directional retardation pattern in a
simple geometry,
\item does the surface-loading field track the geometry in an interpretable
way,
\item does the 2D image case remain visually and numerically easier to audit
than the 3D cases.
\end{enumerate}

\subsection{Simple 3D Image-Based Case}

The planned simple 3D case reuses:
\begin{itemize}
\item \texttt{images/raw/Kelvin1-200x200x200.raw.tar.gz}
\item metadata: \texttt{images/raw/Kelvin1-200x200x200.txt}
\item image size: \mbox{$200 \times 200 \times 200$}
\item voxel size: \mbox{$10~\mu\mathrm{m}$}
\item phase labels: \mbox{$1 = \mathrm{pore}$}, \mbox{$2 = \mathrm{micropore}$}
      in the manuscript rendering convention
\end{itemize}

This case should demonstrate the transition from 2D transport pathways to a
fully 3D unresolved surface network while still remaining easy to interpret.

The simple 3D section should focus on:
\begin{itemize}
\item how 3D topology changes the transport path,
\item how the unresolved internal surface distribution changes the uptake
pattern,
\item how much the 3D case increases chemistry cost relative to the 2D case.
\end{itemize}

The paper figures for the 3D cases should use angled 3D renders rather than
planar slices so the geometry and the later concentration fields read
immediately as volumetric results.

\subsection{Large 3D Porous-Media Case}

The planned large 3D porous-media case reuses:
\begin{itemize}
\item \texttt{images/raw/Est\_3phase500cubed4micron.raw.tar.gz}
\item metadata: \texttt{images/raw/Est\_3phase500cubed4micron.txt}
\item image size: \mbox{$500 \times 500 \times 500$}
\item voxel size: \mbox{$4~\mu\mathrm{m}$}
\item phase labels: \mbox{$1 = \mathrm{pore}$},
      \mbox{$2 = \mathrm{micropores}$},
      \mbox{$3 = \mathrm{solid}$}
\end{itemize}

This case is the application-scale demonstration. It should use an
Estaillades-style multi-scale image so the method is exercised on a domain with
more realistic multi-scale structural contrast than the controlled 2D and
simple 3D cases.

The large porous-media section should report:
\begin{itemize}
\item mesh/image size,
\item effective resolution,
\item visible multi-scale structural contrast in the reported slices,
\item MPI rank count,
\item representative runtime,
\item one concentration metric and one surface-loading metric that remain
comparable to the earlier sections.
\end{itemize}
